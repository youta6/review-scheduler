# 機能一覧：システムに必要な機能は？

### 一般ユーザー

| 機能 | 内容 |
|---|---|
| ユーザー登録 | ユーザー名・パスワードを登録する |
| ログイン | ユーザー名・パスワードで認証しJWTトークンを発行する |
| ユーザー情報取得 | 自分のユーザー情報を取得する |
| ユーザー更新 | 自分のユーザー名・パスワードを更新する |
| ユーザー削除 | 自分のユーザーを論理削除する（削除フラグをTrueに更新） |
| 復習情報登録 | 復習項目・学習日・詳細を登録し、5回分の復習スケジュールを自動生成する |
| 復習情報取得 | 自分の復習情報一覧を取得する |
| 復習情報更新 | 自分の復習項目・詳細・対応済みフラグを更新する |
| 復習情報削除 | 自分の復習情報および紐づく復習スケジュールを削除する |

### 管理者（admin_flag=True）

| 機能 | 内容 |
|---|---|
| 全ユーザー情報取得 | 全ユーザーの情報一覧を取得する |
| ユーザー更新（管理者） | 任意のユーザー情報を更新する |
| ユーザー削除（管理者） | 任意のユーザーを論理削除する |

# 情報・データ：データ項目や処理方法は？

### USERテーブル
| 項目 | 型 | 説明 |
|---|---|---|
| ID | int | 主キー（自動採番） |
| ユーザー名 | str | ユニーク |
| ハッシュ済みパスワード | str | Argon2でハッシュ化 |
| 削除フラグ | bool | 論理削除用 |
| 管理者フラグ | bool | 管理者権限 |
| 作成日時 | datetime | - |
| 更新日時 | datetime | - |

### REVIEWテーブル
| 項目 | 型 | 説明 |
|---|---|---|
| ユーザーID | int | 外部キー |
| 復習項目ID | int | ユーザーごとに採番 |
| 復習項目 | str | - |
| 詳細 | str | 任意 |
| 学習日 | datetime | - |
| 作成日時 | datetime | - |
| 更新日時 | datetime | - |

### REVIEW_MANAGEMENTテーブル
| 項目 | 型 | 説明 |
|---|---|---|
| ユーザーID | int | 外部キー・主キー |
| 復習項目ID | int | 外部キー・主キー |
| 復習回 | int | 主キー（1〜5） |
| 復習日 | datetime | 学習日から自動計算 |
| 対応済みフラグ | bool | 復習完了フラグ |
| 作成日時 | datetime | - |
| 更新日時 | datetime | - |

### 復習日の計算式
| 復習回 | 復習日 |
|---|---|
| 1回目 | 学習日 + 1日 |
| 2回目 | 学習日 + 3日 |
| 3回目 | 学習日 + 7日 |
| 4回目 | 学習日 + 15日 |
| 5回目 | 学習日 + 31日 |

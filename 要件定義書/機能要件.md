# 機能一覧：システムに必要な機能は？

### 一般ユーザー

| 機能 | 内容 |
|---|---|
| ユーザー登録 | ユーザー名・パスワードを登録する |
| ログイン | ユーザー名・パスワードで認証しJWTトークンを発行する |
| ユーザー情報取得 | 自分のユーザー情報を取得する |
| ユーザー更新 | 自分のユーザー名・パスワードを更新する |
| ユーザー削除 | 自分のユーザーを論理削除する（削除フラグをTrueに更新） |
| 復習情報登録 | 復習項目・学習日・詳細を登録し、5回分の復習スケジュールを自動生成する |
| 復習情報取得 | 自分の復習情報一覧を取得する |
| 復習情報更新 | 自分の復習項目・詳細・対応済みフラグを更新する |
| 復習情報削除 | 自分の復習情報および紐づく復習スケジュールを削除する |

### 管理者（admin_flag=True）

| 機能 | 内容 |
|---|---|
| 全ユーザー情報取得 | 全ユーザーの情報一覧を取得する |
| ユーザー更新（管理者） | 任意のユーザー情報を更新する |
| ユーザー削除（管理者） | 任意のユーザーを論理削除する |

- 管理者ユーザーは環境変数（ADMIN_SECRET_KEY_NAME・ADMIN_SECRET_KEY_PASSWORD）で管理するシード管理者のみ作成可能
- 一般ユーザーのユーザー登録では管理者フラグをTrueにすることはできない


# 認証・認可要件：各機能の認証要否とアクセス制御

### 認証要否

| 機能 | 認証要否 |
|---|---|
| ユーザー登録 | 不要 |
| ログイン | 不要 |
| ユーザー情報取得 | 要（JWTトークン） |
| ユーザー更新 | 要（JWTトークン） |
| ユーザー削除 | 要（JWTトークン） |
| 全ユーザー情報取得 | 要（JWTトークン・管理者のみ） |
| ユーザー更新（管理者） | 要（JWTトークン・管理者のみ） |
| ユーザー削除（管理者） | 要（JWTトークン・管理者のみ） |
| 復習情報登録 | 要（JWTトークン） |
| 復習情報取得 | 要（JWTトークン） |
| 復習情報更新 | 要（JWTトークン） |
| 復習情報削除 | 要（JWTトークン） |

### 認可ルール
- 一般ユーザーは自分のデータのみ操作可能（リクエストの user_id と JWTトークンの user_id が一致する場合のみ許可）
- 管理者（admin_flag=True）は全ユーザーのデータを操作可能


# ビジネスルール：システム固有の業務ルール

### 論理削除ユーザーのログイン
- 削除フラグがTrueのユーザーはログイン不可
- 削除済みユーザーでログインを試みた場合はHTTP 401を返す

### ユーザー論理削除時のデータ扱い
- ユーザーを論理削除した場合、紐づく復習情報（REVIEWテーブル・REVIEW_MANAGEMENTテーブル）はデータを保持する
- 削除済みユーザーはログイン不可のため、保持されたデータには事実上アクセスできない

# 情報・データ：データ項目や処理方法は？

### USERテーブル
| 項目 | 型 | 説明 | 制約 |
|---|---|---|---|
| ID | int | 主キー（自動採番） | - |
| ユーザー名 | str | ユニーク | 1〜50文字 |
| ハッシュ済みパスワード | str | Argon2でハッシュ化 | システム生成（上限255文字） |
| 削除フラグ | bool | 論理削除用 | デフォルト：False |
| 管理者フラグ | bool | 管理者権限 | デフォルト：False |
| 作成日時 | datetime | - | - |
| 更新日時 | datetime | - | - |

### REVIEWテーブル
| 項目 | 型 | 説明 | 制約 |
|---|---|---|---|
| ユーザーID | int | 外部キー | - |
| 復習項目ID | int | ユーザーごとに採番 | 1〜999 |
| 復習項目 | str | - | 1〜200文字 |
| 詳細 | str | 任意 | 1〜1000文字（任意項目） |
| 学習日 | datetime | - | - |
| 作成日時 | datetime | - | - |
| 更新日時 | datetime | - | - |

### REVIEW_MANAGEMENTテーブル
| 項目 | 型 | 説明 | 制約 |
|---|---|---|---|
| ユーザーID | int | 外部キー・主キー | - |
| 復習項目ID | int | 外部キー・主キー | 1〜999 |
| 復習回 | int | 主キー（1〜5） | 1〜5 |
| 復習日 | datetime | 学習日から自動計算 | - |
| 対応済みフラグ | bool | 復習完了フラグ | デフォルト：False |
| 作成日時 | datetime | - | - |
| 更新日時 | datetime | - | - |

### 復習日の計算式
| 復習回 | 復習日 |
|---|---|
| 1回目 | 学習日 + 1日 |
| 2回目 | 学習日 + 3日 |
| 3回目 | 学習日 + 7日 |
| 4回目 | 学習日 + 15日 |
| 5回目 | 学習日 + 31日 |

# 業務要件一覧：業務内容や実施担当者をまとめる

| 業務 | 内容 | 担当者 |
|---|---|---|
| ユーザー管理 | ユーザーの登録・ログイン・更新・削除 | 利用者 |
| 復習情報管理 | 復習項目の登録・取得・更新・削除 | 利用者 |
| 復習スケジュール管理 | 復習情報と連動した復習スケジュールの自動生成・更新・削除 | システム自動処理 |


# 業務フロー図：業務の流れを図でまとめる

```
ユーザー登録 → ログイン → 復習情報登録 → 復習スケジュール自動生成
                                ↓
                        復習スケジュール確認
                                ↓
                        対応済みフラグ更新
```


# 規模：どれぐらいの規模を想定しているか？
- 想定利用者：不特定多数
- 同時利用者数：最大10人


# 時期・時間：業務を行う時期やかかる時間は？
- 利用者が任意のタイミングで使用する
- オンデマンド起動のため、常時稼働は前提としない


# 場所：どこでシステムが使われるか？
- インターネット接続環境があればどこでも利用可能
- クライアントはAPIクライアント（ブラウザ・アプリ等）


# 指標：業務上ベンチマークとなる指標は？
- 復習スケジュールの遵守率（利用者が期日通りに復習を完了しているか）


# システム化の範囲：システム化の対象／対象外となる業務範囲は？

| 区分 | 内容 |
|---|---|
| 対象 | ユーザー管理・復習情報管理・復習スケジュール管理 |
| 対象外 | 学習コンテンツの提供・通知機能・フロントエンド画面（将来対応） |
